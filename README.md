# Data Structures Project: Skyscraper Stack Builder Game

## Project Overview

Skyscraper Stack Builder Game is a Data Structures-based project developed as part of our coursework. The project was designed and implemented by me and my partner Zahra Shah. The game is inspired by a block-stacking concept similar to classic mobile stacking games.

The objective of this project was to apply core Data Structures and Object-Oriented Programming concepts in a practical and interactive application.

---

## Game Description

* The player controls a horizontally moving block.
* The block must be placed accurately on top of the previous block.
* Each successful placement increases the player’s score.
* As the game progresses, the speed of block movement increases, making it more challenging.
* If the block does not align with the previous stack, the game ends.
* At the end of the game, a scoreboard displays the top three highest scores along with player names.

---

## Data Structures and Programming Concepts Used

### Stack Data Structure

A stack is used to store and manage successfully placed blocks in a Last-In-First-Out (LIFO) order. Each new block is pushed onto the stack when placed correctly.

### Game State Management

Different game states are managed such as:

* Active gameplay
* Score updating
* Game over state

### Event Handling

Event handling is used to manage:

* User input for block placement
* Timing of block movement and actions

### Loops and Conditional Logic

Loops and conditions are used to control:

* Continuous movement of blocks
* Collision detection
* Score calculation
* Speed increase over time

### Object-Oriented Programming (OOP)

The project is structured using classes and objects to ensure:

* Modular design
* Code reusability
* Better organization and readability

### Java Swing (GUI)

Java Swing is used to design the graphical user interface, including:

* Game window
* Moving blocks
* Scoreboard display
